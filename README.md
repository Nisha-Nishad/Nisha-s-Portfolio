# Nisha Nishad — Developer Portfolio

A modern, high-performance, and responsive developer portfolio website live at [nishanishad.netlify.app](https://nishanishad.netlify.app/).

🌐 **Live Website:** [https://nishanishad.netlify.app/](https://nishanishad.netlify.app/)  
📁 **GitHub Repository:** [https://github.com/Nisha-Nishad/Nisha-s-Portfolio](https://github.com/Nisha-Nishad/Nisha-s-Portfolio)

---

## 💻 Tech Stack & Tools

- **Frontend:** React 18, TypeScript, Tailwind CSS, HTML5 & CSS3
- **Build Tool:** Vite
- **Icons & UI:** Lucide React
- **Backend & Database:** Supabase (Optional integration for contact form persistence)
- **Deployment:** Netlify
- **Core Languages & Tools:** C, C++, Java, Python, Flutter, JavaScript, TypeScript, Git & GitHub, Postman, VS Code

---

## ✨ Key Features

- **Modern & Responsive Design:**
  - Dark theme with warm accents, smooth animations, and clean typography.
  - Fully optimized for mobile, tablet, and desktop viewports.
- **Hero Section:**
  - Professional title: *Web Developer | AI & ML Engineer* (B.Tech CSE AIML Graduate).
  - Quick contact CTAs and social profile links (LinkedIn, GitHub, Twitter/X, Email).
- **About Section:**
  - Academic background and technical vision.
  - Focus areas: Web Development, AI/ML Engineering, and Core Programming Languages (C, C++, Java, Python, Flutter).
- **Skills Section:**
  - Dynamic infinite-scrolling marquee ribbon.
  - 4 structured skill categories: *Frontend Engineering*, *Backend & Database*, *AI & Machine Learning*, and *Programming & Developer Tools*.
- **Featured Projects:**
  - **ShopEase (E-Commerce Platform):** Full-stack responsive web application featuring curated product categories, dynamic search, interactive cart, wishlist, and smooth order checkout flow.
- **Certifications & Credentials:**
  - Interactive touch-friendly certification credentials showcase (MERN Stack, IBM Generative AI, NPTEL Cloud IoT & Edge ML, NPTEL Big Data Computing).
- **Contact & Connect:**
  - Direct contact cards (Email, LinkedIn, Twitter/X) and a validated contact form.
- **Open Graph Social Share Banner:**
  - Custom 1200x630 banner preview for rich cards on WhatsApp, LinkedIn, Twitter/X, and Discord.

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/Nisha-Nishad/Nisha-s-Portfolio.git
cd Nisha-s-Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
